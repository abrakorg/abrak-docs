# Security policy

## Reporting a vulnerability

Please do **not** open a public issue for a security problem.

Email **admin@abrak.org** with:

- what you found and where,
- the steps to reproduce it,
- what an attacker could do with it.

You will get an acknowledgement within two working days. We will tell you when the
issue is fixed, and we are happy to credit you publicly unless you would rather stay
anonymous.

## Scope

This repository holds documentation only. Reports about the hosted platform
(`abrak.org` and tenant subdomains `*.abrak.org`) are in scope for the email address
above. Reports about Odoo itself belong with
[Odoo's own security team](https://www.odoo.com/security-report).

## What we ask

Please do not run automated scanners against tenant subdomains, do not access data
that is not yours, and do not degrade the service for other customers while testing.
