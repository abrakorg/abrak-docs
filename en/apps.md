# App catalogue

[← Back to contents](README.md)

Abrak ships **82 apps** you can switch on. They all run on one database and one shared
data model — the sales invoice sees the same product Inventory counts and the same
customer CRM is tracking.

The live catalogue, with a page per app: <https://abrak.org/apps>

## What only Abrak has

These do not exist in stock Odoo; Abrak wrote them:

| App | What it does |
|---|---|
| Jalali Calendar Pro | Solar Hijri dates system-wide — forms, reports, fiscal periods, due dates |
| Moadian | Sends electronic invoices from Odoo to Iran's tax portal |
| Iranian Accounting | Sayad cheques, statutory ledgers, withholding tax, Article 169, balance sheet |
| Iranian Payroll | Payslips that follow the annual Ministry of Labour rulings |
| Social Insurance | Monthly insurance list and the DBF export the state system expects |
| Abrak SMS | SMS on a licensed domestic gateway, paid from a Rial wallet |
| Cloud telephony | Click-to-dial from CRM, automatic call logging, dedicated numbers |
| WooCommerce connector | Two-way sync of products, stock, prices and orders |
| Torob connector | A signed product feed from Odoo to torob.com |
| Instagram suite | Automatic product publishing, direct-message and comment automation |
| Smart attendance | Clock-in by GPS geofence, rotating QR code, or messenger |
| MCP server | Connects AI assistants to live ERP data under explicit controls |
| AI gateway | Language-model access with a Rial wallet and an OpenAI-compatible API |
| Remove branding | Removes the mandatory "powered by" link from the login page |

## A note on price

Apps are **not priced individually**. The standard plan gives access to all of them and
you pay per internal user. Bundles exist that cost less than buying the same apps
separately. See [Pricing](pricing.md).

## Commercial modules for self-hosting

If you host Odoo yourself, some modules are sold separately. Each app's page on
<https://abrak.org/apps> states the supported Odoo versions and licence terms.
