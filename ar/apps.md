# فهرس التطبيقات

[← العودة إلى الفهرس](README.md)

تقدّم أبرك **٨٢ تطبيقًا** قابلًا للتفعيل. تعمل كلها على قاعدة بيانات واحدة ونموذج
بيانات مشترك — فاتورة البيع ترى المنتج نفسه الذي يعدّه المخزون، والعميل نفسه الذي
يتابعه نظام إدارة علاقات العملاء.

الفهرس الحيّ الكامل، بصفحة لكل تطبيق: <https://abrak.org/apps>

## الفئات

| الفئة | العدد | أمثلة |
|---|---|---|
| الإنتاجية | ٢٥ | المستندات، التوقيع الإلكتروني، المشاريع، التقويم، الدردشة المباشرة، الاستبيانات |
| التكييف الإيراني | ١٢ | التقويم الجلالي، مؤديان، شيكات صياد، الرواتب الإيرانية، التأمين الاجتماعي |
| الموارد البشرية | ٩ | الموظفون، الحضور والانصراف، الإجازات، التوظيف، التقييم، المهارات |
| سلسلة التوريد | ٩ | المخزون، الباركود، المشتريات، التصنيع، ضبط الجودة، الإصلاحات، الأسطول |
| المبيعات | ٨ | إدارة علاقات العملاء، أوامر البيع، الاشتراكات، التأجير، نقاط البيع، المطاعم |
| الموقع الإلكتروني | ٨ | منشئ المواقع، المتجر الإلكتروني، المدوّنة، المنتدى، التعليم الإلكتروني، الفعاليات |
| التسويق | ٧ | أتمتة التسويق، البريد الإلكتروني، الرسائل القصيرة الجماعية، الشبكات الاجتماعية |
| المالية | ٣ | المحاسبة، نفقات الموظفين، حقوق الملكية |
| القوالب | ١ | قالب متجر الإلكترونيات |

## ما تنفرد به أبرك

هذه غير موجودة في أودو القياسي، وقد كتبتها أبرك:

| التطبيق | وظيفته |
|---|---|
| التقويم الجلالي المحترف | تواريخ هجرية شمسية في كامل النظام — النماذج، التقارير، الفترات المالية، تواريخ الاستحقاق |
| مؤديان | إرسال الفواتير الإلكترونية من أودو إلى بوّابة الضرائب الإيرانية |
| المحاسبة الإيرانية | شيكات صياد، الدفاتر القانونية، الضريبة المقتطعة، المادة ١٦٩، الميزانية العمومية |
| الرواتب الإيرانية | قسائم رواتب وفق قرارات وزارة العمل السنوية |
| التأمين الاجتماعي | القائمة الشهرية وتصدير ملف DBF الذي يطلبه النظام الحكومي |
| رسائل أبرك القصيرة | رسائل قصيرة عبر بوّابة محلية مرخّصة، بمحفظة بالريال |
| الهاتف السحابي | اتصال بنقرة من داخل إدارة علاقات العملاء، تسجيل تلقائي للمكالمات، أرقام مخصّصة |
| موصّل ووكومرس | مزامنة ثنائية الاتجاه للمنتجات والمخزون والأسعار والطلبات |
| موصّل ترب | تغذية منتجات موقّعة من أودو إلى torob.com |
| حزمة إنستغرام | نشر تلقائي للمنتجات، أتمتة الرسائل المباشرة والتعليقات |
| الحضور الذكي | تسجيل الحضور بالموقع الجغرافي أو رمز QR متغيّر أو تطبيق مراسلة |
| خادم MCP | يربط مساعدي الذكاء الاصطناعي ببيانات النظام الحيّة ضمن ضوابط صريحة |
| بوّابة الذكاء الاصطناعي | وصول إلى النماذج اللغوية بمحفظة بالريال وواجهة متوافقة مع OpenAI |
| إزالة العلامة التجارية | إزالة رابط «مدعوم من» الإلزامي من صفحة الدخول |

## ملاحظة عن السعر

التطبيقات **لا تُسعَّر فرديًا**. الخطة القياسية تمنح الوصول إليها جميعًا، وأنت تدفع لكل
مستخدم داخلي. توجد أيضًا حزم جاهزة أرخص من شراء التطبيقات نفسها منفصلة. انظر
[التسعير](pricing.md).

## وحدات تجارية للاستضافة الذاتية

إن كنت تستضيف أودو بنفسك، تُباع بعض الوحدات منفصلة. صفحة كل تطبيق على
<https://abrak.org/apps> توضّح إصدارات أودو المدعومة وشروط الترخيص.
