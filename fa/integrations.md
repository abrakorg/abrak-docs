### ووکامرس

همگام‌سازی دوطرفه بین اودوو و یک یا چند فروشگاه ووکامرس:

- محصول، موجودی، قیمت و سفارش در هر دو جهت
- نگاشت خودکار ویژگی و مقدار (رنگ، سایز)، با امکان پین‌کردن دستی برای نام‌های خاص
- صف همگام‌سازی با وضعیت و تعداد تلاش هر کار
- سیاست حل تعارض، وقتی هر دو طرف یک رکورد را تغییر داده‌اند

راهنمای گام‌به‌گام: <https://abrak.org/woocommerce-odoo>

راهنما: <https://abrak.org/torob-odoo>

- پاسخ خودکار به دایرکت و کامنت، با اندازه‌گیری واقعی قیف فروش

### سرور MCP

MCP (Model Context Protocol) استانداردی است که به دستیار هوش مصنوعی اجازه می‌دهد
به دادهٔ زندهٔ سیستم شما وصل شود — مثلاً «موجودی انبار تهران را بگو» یا «فاکتور این
سفارش را صادر کن».

کنترل‌هایی که ابرک روی آن گذاشته است:

- کلید API با انتخاب کاربر اودو — دستیار بیش از دسترسی همان کاربر نمی‌بیند
- تعیین دامنهٔ دسترسی، سقف نرخ و مدل‌های مجاز
- آزمایشگاه تست ابزار، پیش از اتصال کلاینت واقعی
- تأیید تغییرها و گزارش ممیزی

پیش از دادن کلید به یک دستیار،
[چک‌لیست امنیتی کلیدهای MCP](https://abrak.org/blog) را بخوانید.

راهنما: <https://abrak.org/mcp-odoo>

## وب‌هوک امضاشده

اکشن بومی «ارسال اعلان وب‌هوک» اودوو (قابل استفاده در قواعد اتوماسیون) در ابرک یک «کلید امضای وب‌هوک» دارد که فقط مدیر سیستم می‌بیند. اگر کلید تنظیم شود، هر فراخوانی POST سه سرآیند دارد:

- `X-Abrak-Event-Id`: شناسهٔ یکتای هر فراخوانی؛ تکراری‌ها را با آن کنار بگذارید.
- `X-Abrak-Timestamp`: زمان به ثانیهٔ یونیکس.
- `X-Abrak-Signature: sha256=<hex>`: امضای HMAC-SHA256 با همان کلید روی بایت‌های `"<timestamp>." + <بدنهٔ خام>`.

گیرنده امضا را روی بدنهٔ خام دوباره حساب کند، با مقایسهٔ زمان‌ثابت بسنجد و درخواست‌های قدیمی‌تر از حدود ۵ دقیقه را رد کند. بدون کلید، رفتار بومی اودوو تغییری نمی‌کند.

```python
import hmac, hashlib, time

def verify(secret: str, headers: dict, raw_body: bytes, max_age=300) -> bool:
    ts = headers.get("X-Abrak-Timestamp", "")
    sig = headers.get("X-Abrak-Signature", "")
    if not ts.isdigit() or abs(time.time() - int(ts)) > max_age:
        return False
    expected = "sha256=" + hmac.new(secret.encode(), ts.encode() + b"." + raw_body,
                                    hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, sig)
```
