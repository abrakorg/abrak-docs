# کاتالوگ اپلیکیشن‌ها

[← بازگشت به فهرست](README.md)

ابرک **۸۲ اپلیکیشن** قابل فعال‌سازی دارد. همه روی یک دیتابیس و یک مدل دادهٔ مشترک
کار می‌کنند — فاکتور فروش همان محصولی را می‌بیند که انبار می‌شمارد و همان مشتری‌ای
را که CRM دنبال می‌کند.

فهرست زندهٔ کامل با توضیح هر اپ: <https://abrak.org/apps>

## دسته‌ها

| دسته | تعداد اپ | نمونه |
|---|---|---|
| بهره‌وری | ۲۵ | اسناد، امضای دیجیتال، پروژه، تقویم، گفتگوی آنلاین، نظرسنجی |
| بومی‌سازی ایران | ۱۲ | تقویم جلالی، مؤدیان، چک صیادی، حقوق ایران، بیمهٔ تأمین اجتماعی |
| منابع انسانی | ۹ | کارمندان، حضور و غیاب، مرخصی، جذب و استخدام، ارزیابی، مهارت‌ها |
| زنجیرهٔ تأمین | ۹ | انبار، بارکد، خرید، تولید (MRP)، کنترل کیفیت، تعمیرات، ناوگان |
| فروش | ۸ | CRM، سفارش فروش، اشتراک، اجاره، فروش حضوری (POS)، رستوران |
| وب‌سایت | ۸ | سایت‌ساز، فروشگاه آنلاین، بلاگ، انجمن، آموزش آنلاین، رویداد |
| بازاریابی | ۷ | اتوماسیون بازاریابی، ایمیل، پیامک انبوه، شبکه‌های اجتماعی، کارت بازاریابی |

## اپ‌هایی که فقط ابرک دارد

این‌ها در اودوو استاندارد وجود ندارند و ابرک آن‌ها را نوشته است:

| اپ | کار آن |
|---|---|
| تقویم جلالی حرفه‌ای | تاریخ شمسی در کل سیستم — فرم، گزارش، دورهٔ مالی، سررسید |
| سامانهٔ مؤدیان | ارسال صورتحساب الکترونیکی از اودوو به کارپوشه |
| حسابداری ایران | چک صیادی، دفاتر قانونی، مالیات تکلیفی، ماده ۱۶۹، ترازنامه |
| حقوق و دستمزد ایران | فیش حقوقی طبق مصوبات سالانهٔ وزارت کار |
| بیمهٔ تأمین اجتماعی | فهرست ماهانهٔ بیمه و خروجی DBF برای سامانهٔ سازمان |
| پیامک ابرک | پیامک با کیف‌پول ریالی روی زیرساخت معتبر داخلی |
| تلفن ابری | تماس از داخل CRM، ثبت خودکار تماس، شماره‌گیری با یک کلیک |
| کانکتور ووکامرس | همگام‌سازی دوطرفهٔ محصول، موجودی، قیمت و سفارش |
| کانکتور ترب | فید امضاشدهٔ محصولات از اودوو به ترب |
| اینستاگرام | انتشار خودکار محصول، پاسخ خودکار دایرکت و کامنت |
| حضور و غیاب هوشمند | ثبت تردد با GPS، کیو-آر چرخان یا پیام‌رسان |
| سرور MCP | اتصال دستیارهای هوش مصنوعی به دادهٔ زندهٔ ERP |
| دروازهٔ هوش مصنوعی | دسترسی به مدل‌های زبانی با کیف‌پول ریالی و API سازگار با OpenAI |
| حذف برندینگ | برداشتن بک‌لینک اجباری از صفحهٔ ورود |

## نکتهٔ مهم دربارهٔ قیمت

اپ‌ها **جداگانه قیمت نمی‌خورند**. پلن استاندارد به همهٔ اپ‌ها دسترسی می‌دهد و شما
به ازای هر کاربر داخلی پرداخت می‌کنید. پکیج‌های آماده هم وجود دارند که از خرید جدای
همان اپ‌ها ارزان‌ترند. جزئیات در [صفحهٔ قیمت‌گذاری](pricing.md).

## اپ‌های تجاری برای نصب خودتان

اگر اودوو را خودتان میزبانی می‌کنید، بعضی ماژول‌ها را می‌توانید جدا بخرید. صفحهٔ هر
اپ در <https://abrak.org/apps> نسخه‌های پشتیبانی‌شدهٔ اودوو و شرایط لایسنس را
مشخص می‌کند.
